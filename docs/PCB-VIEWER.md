# PCB Preview integration

The existing Preview tab lazy-loads `src/components/pcb-viewer/PCBViewer.tsx` through `next/dynamic` with SSR disabled. The adapter loads the locally vendored KiCanvas module once and fetches the project's real `.kicad_pcb`. It uses the official `kicanvas-embed` / inline `kicanvas-source` API with `controls="full"`. Geometry, layers, picking, coordinates, zoom and pan are all rendered and managed by KiCanvas.

## Add another PCB

1. Copy its `.kicad_pcb` into `public/assets/projects/personal/<slug>/`.
2. Add this property to that project in `data/example-projects.json`:

```json
"pcbSource": {
  "src": "/assets/projects/personal/<slug>/board.kicad_pcb",
  "title": "Project name · PCB name"
}
```

3. Build and open the Preview tab. The native layer manager derives available copper and technical layers from the actual document; no layer count is hard-coded.

A project with no source shows an explicit unavailable message. A failed or unsupported file shows an error and Retry; it is never replaced with a screenshot. Interactive BOM has separate data and components and is unchanged.

## Native API limits and pinned bridge

KiCanvas's official embedding documentation describes an alpha API. `theme`, `zoom` and embed error/selection events are not fully implemented. There is no stable embed-level API for external Fit Board or layer-sidebar controls.

`KiCanvasAdapter.ts` contains a deliberately small, version-specific bridge to the **existing upstream** `KCBoardViewerElement.viewer`, `BoardViewer.zoom_to_board()`, `draw()` and `select(null)`. No methods are invented. Fit Board uses KiCanvas's actual Edge.Cuts bounds. Reset clears the native selection and restores those bounds without resetting layer visibility. The native sidebar's `collapsed` attribute controls its display. The real preference controls apply Witch Hazel and KiCad navigation (wheel zoom; middle/right drag pan). Component properties and layer presets remain native UI; there are no duplicated layer toggles or custom selection algorithms.

Source references:
- https://kicanvas.org/embedding/
- https://github.com/theacodes/kicanvas/blob/main/src/viewers/board/viewer.ts
- https://github.com/theacodes/kicanvas/blob/main/src/kicanvas/elements/kc-board/viewer.ts
- https://github.com/theacodes/kicanvas/blob/main/src/kicanvas/elements/kicanvas-embed.ts

Do not update the vendored module without rerunning the integration checks: native DOM names and this bridge are not a stable public API. The adapter verifies supported methods and surfaces initialization failures. Documented load events are listened to in capture phase, with a reflected native loaded-state check and timeout. KiCanvas-specific load rejections are surfaced to the user.

Hover-only footprint tooltips are not added: inspection uses native click selection, Footprints and Properties panels. The alpha embedding API does not offer a stable external component-selection event contract. Wheel cursor anchoring and touch gestures retain upstream behavior.

The supplied MP1 file was generated by KiCad 10. The current KiCanvas parser warns about newer manufacturing/footprint metadata (for example tenting and unit metadata) it does not model. Verify future KiCad files individually. This preview is inspection tooling, not an electrical/design-rule checker or fabrication sign-off. It does not add 3D, infer missing layer data, or generate geometry.

## Hosting and lifecycle

All runtime assets are same-origin static files, including KiCanvas's icon font. No CDN, API, worker backend, database or server-side conversion is required. Cloudflare's existing CSP permits these same-origin scripts, fonts and board fetches.

The tab creates one viewer on first visit and retains it while switching tabs, preserving native view and layers. Native resize observation updates the canvas on return/fullscreen. Unmounting removes the custom element so KiCanvas disposes its WebGL renderer and event handlers; the adapter removes its timers, listeners and observers and cancels pending source fetches. Retry reuses the registered module.
